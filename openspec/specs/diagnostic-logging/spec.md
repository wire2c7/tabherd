# diagnostic-logging Specification

## Purpose

不具合の調査のため、拡張機能の処理とエラーの記録を利用者の端末に残し、利用者が書き出して報告に添付できるようにする。記録には閲覧先が分かる情報を含めない。

## Requirements

### Requirement: エラー時のログの保存

拡張機能は、警告またはエラーが起きたとき、そのログと、その直前に起きた処理のログを端末に保存しなければならない（MUST）。警告・エラーが起きていないあいだの処理のログは端末に保存してはならない（MUST NOT）。保存は警告・エラーのたびに行い、1回の保存の後は、次の警告・エラーまで処理のログを保存してはならない（MUST NOT）。

#### Scenario: グループの操作が失敗する

- **WHEN** タブをグループへ入れる操作が、タブが閉じられた等の理由で失敗する
- **THEN** 失敗のログと、そのタブの判定を始めたログが端末に保存される

#### Scenario: エラーが起きない

- **WHEN** エラーなくタブがグループへ入る
- **THEN** 端末に保存されたログは増えない

#### Scenario: 捕捉されないエラー

- **WHEN** バックグラウンドの処理で、拡張機能のコードが捕捉しないエラーが起きる
- **THEN** そのエラーのログが端末に保存される

### Requirement: 保存するログの件数

端末に保存するログは直近の 500 件までとし、超えた分は古いものから捨てなければならない（MUST）。

#### Scenario: 上限を超える

- **WHEN** 500 件のログが保存された状態で、さらにログが保存される
- **THEN** 最も古いログから捨てられ、保存されたログは 500 件のままになる

### Requirement: 記録する情報の範囲

ログには、時刻・レベル・処理の種類・タブ・グループ・ウィンドウの ID・件数・エラーの内容だけを記録しなければならない（MUST）。タブの URL・タイトル、グループ名、ルールの内容（グループ名・条件）をログに記録してはならない（MUST NOT）。

#### Scenario: グループを作る操作が失敗する

- **WHEN** ルールのグループ名でグループを作る操作が失敗する
- **THEN** 保存されたログには操作の種類とタブの ID が含まれ、グループ名とタブの URL は含まれない

### Requirement: 開発中の console への出力

開発ビルドでは、処理のログを debug 以上ですべて console に出さなければならない（MUST）。リリース版では、console には警告以上だけを出さなければならない（MUST）。

#### Scenario: 開発ビルドでタブを開く

- **WHEN** 開発ビルドでタブを開き、ルールに一致する URL になる
- **THEN** Service Worker の console に、タブの判定と操作のログが出る

### Requirement: ログの説明

オプションページには「ログ」の節を置き、ログを残す目的、記録するもの、記録しないもの、ログが端末にのみ保存され自動で送信されないこと、保存する件数の上限を表示しなければならない（MUST）。

#### Scenario: オプションページを開く

- **WHEN** 拡張機能のオプションページを開く
- **THEN** ルールの一覧の下に「ログ」の節があり、記録するもの・記録しないもの・自動で送信されないことが表示される

### Requirement: ログの書き出し

オプションページの「ログを保存」は、端末に保存されたログを、拡張機能のバージョンと、ブラウザの種類・バージョンを添えて JSON ファイルとしてダウンロードさせなければならない（MUST）。ブラウザの種類・バージョンは、ブラウザが User-Agent Client Hints に対応していればそこから正確な値を、対応していなければ User-Agent から読める範囲の値を添えなければならない（MUST）。保存されたログが無いときも、空のログのファイルを書き出せなければならない（MUST）。書き出せなかったときは、そのことをオプションページに表示しなければならない（MUST）。

#### Scenario: ログを書き出す

- **WHEN** ログが保存された状態で「ログを保存」を押す
- **THEN** 保存されたログと、拡張機能のバージョン、ブラウザの種類・バージョンを含む JSON ファイルがダウンロードされる

#### Scenario: ログを書き出せない

- **WHEN** 保存されたログを読めない状態で「ログを保存」を押す
- **THEN** ログを保存できなかったことがオプションページに表示される

### Requirement: ログの消去

オプションページの「ログを消去」は、端末に保存されたログをすべて消さなければならない（MUST）。ログの保存と消去は受け取った順に1つずつ処理し、消去を依頼する前に出たログ（保存の途中のもの、エラーの直前の文脈としてまだ保存していないものを含む）を消去の後に残してはならない（MUST NOT）。消去を依頼した後に出たログは、消してはならない（MUST NOT）。消去できなかったときは、そのことをオプションページに表示しなければならない（MUST）。

#### Scenario: ログを消去する

- **WHEN** ログが保存された状態で「ログを消去」を押し、続けて「ログを保存」を押す
- **THEN** 書き出したファイルのログは空になる

#### Scenario: 保存の途中で消去する

- **WHEN** エラーのログを端末へ保存している途中で「ログを消去」を押し、その後に別のエラーが起きる
- **THEN** 消去の前のログはすべて消え、後のエラーのログだけが保存されている

#### Scenario: ログを消去できない

- **WHEN** 消去をバックグラウンドに依頼できない状態で「ログを消去」を押す
- **THEN** ログを消去できなかったことがオプションページに表示され、保存されたログの件数は変わらない
