# Spec Delta

## MODIFIED Requirements

### Requirement: 入力の検証

構文が不正な正規表現の条件、空のグループ名、重複して無効になるグループ名（grouping-rules の「ルールの有効性」）には、該当する入力欄の近くにエラーを表示しなければならない（MUST）。値が空の正規表現の条件は入力途中でもあるため、エラーを表示してはならない（MUST NOT）。エラーがあっても入力内容は保存し、そのルール・条件は自動グルーピングで無効として扱われなければならない（MUST）。

#### Scenario: 不正な正規表現

- **WHEN** 正規表現の条件に `(` を入力する
- **THEN** その条件の近くに正規表現が不正である旨のエラーが表示される

#### Scenario: グループ名の重複

- **WHEN** 2番目のルールのグループ名を1番目と同じにする
- **THEN** 2番目のルールのグループ名の近くにエラーが表示される

#### Scenario: 下のルールのグループ名にする

- **WHEN** 2番目のルール「業務」のグループがある状態で、1番目のルールのグループ名を「業務」にする
- **THEN** 1番目のルールのグループ名の近くにエラーが表示され、2番目のルールにはエラーが表示されない
