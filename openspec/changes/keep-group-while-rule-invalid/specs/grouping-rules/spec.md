# Spec Delta

## MODIFIED Requirements

### Requirement: ルールの有効性

グループ名が空（前後の空白を除いて空）のルールは無効とし、判定の対象にしてはならない（MUST NOT）。グループ名が、ほかのルールが持っているタイトル（auto-grouping の「ルールの変更の反映」。無効なあいだ持ち続けるタイトルを含む）と同じルールは無効としなければならない（MUST）。ただし、互いに相手が持っているタイトルをグループ名にしたルール（名前の入れ替え）は、どれも有効としなければならない（MUST）。どのルールもタイトルとして持っていないグループ名が複数のルールで同じときは、一覧で最も上のルールを有効とし、ほかは無効としなければならない（MUST）。

#### Scenario: グループ名が空

- **WHEN** グループ名が空のルールの条件に一致する URL を判定する
- **THEN** そのルールには一致しないものとして扱う

#### Scenario: グループ名の重複

- **WHEN** 1番目と3番目のルールのグループ名がどちらも「開発」で、どちらも「開発」のタイトルを持っていない
- **THEN** 3番目のルールは判定の対象にならない

#### Scenario: 後から同じグループ名にする

- **WHEN** 2番目のルールが「業務」のタイトルを持っていて、1番目のルールのグループ名を「業務」にする
- **THEN** 1番目のルールは判定の対象にならず、2番目のルールは判定の対象のまま

#### Scenario: 名前を入れ替える

- **WHEN** ルール「開発」「資料」がそれぞれのタイトルを持っていて、グループ名を「資料」「開発」に入れ替える
- **THEN** どちらのルールも判定の対象になる

#### Scenario: 名前を空にしたルールのタイトルにする

- **WHEN** ルール「開発」のグループ名を空にした後、別のルールのグループ名を「開発」にする
- **THEN** その別のルールは判定の対象にならない
