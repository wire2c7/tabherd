# Spec Delta

## MODIFIED Requirements

### Requirement: ルールの保存

ルールの一覧は拡張機能のローカルストレージに保存し、ブラウザを再起動しても保たなければならない（MUST）。ルールが1つも保存されていないときは、空の一覧として扱わなければならない（MUST）。

#### Scenario: 初回インストール時

- **WHEN** 拡張機能をインストールした直後にルールの一覧を読み込む
- **THEN** サンプルルール3件（設定・動画・ブログ）が投入された状態で読み込まれる

#### Scenario: 再起動後も残る

- **WHEN** ルールを保存してからブラウザを再起動する
- **THEN** 保存したルールの一覧が同じ順番で読み込まれる

## ADDED Requirements

### Requirement: 初回インストール時のサンプルルールの投入

拡張機能のインストールイベントの理由が「install」であり、かつルールの一覧が1件も保存されていないときにだけ、サンプルルールを3件、一覧の末尾に順番に追加して保存しなければならない（MUST）。それ以外の理由（update 等）のときや、既にルールが1件以上保存されているときは、サンプルルールを追加してはならない（MUST NOT）。

#### Scenario: 初回インストール

- **WHEN** 拡張機能を初めてインストールする
- **THEN** 「⚙設定」「📺️動画」「📃ブログ」の3件のルールがこの順で保存される

#### Scenario: 拡張機能の更新

- **WHEN** 拡張機能をバージョンアップし、インストールイベントの理由が「update」である
- **THEN** サンプルルールは追加されない

#### Scenario: 既にルールがある状態でのインストールイベント

- **WHEN** インストールイベントの理由が「install」だが、既に1件以上のルールが保存されている
- **THEN** サンプルルールは追加されない

### Requirement: サンプルルールの内容

投入するサンプルルールは次の3件とし、この順で保存しなければならない（MUST）。

1. グループ名 `⚙設定`、条件: URL の部分一致 `chrome://`
2. グループ名 `📺️動画`、条件: URL の部分一致 `youtube.com`・`nicovideo.jp`・`netflix.com`・`twitch.tv`（いずれか1つに一致すればよい）
3. グループ名 `📃ブログ`、条件: タイトルの部分一致 `ブログ`・URL の部分一致 `blog`（いずれか1つに一致すればよい）

色は、ルールの一覧に既存のルールが無い状態から順番に、未使用の色を割り当てるルール（grey を除く GROUP_COLORS の順）で決めなければならない（MUST）。

#### Scenario: 色の割り当て

- **WHEN** サンプルルールを投入する
- **THEN** 「⚙設定」「📺️動画」「📃ブログ」の色は、GROUP_COLORS（grey を除く）の先頭から順に異なる色になる
