# Spec Delta

## Purpose

タブグループ単位で、利用者が任意のタイミングでタブをサスペンド（メモリ解放）できるようにし、作成元を問わずすべてのタブグループを対象にする。

## ADDED Requirements

### Requirement: グループ一覧とサスペンド操作の表示

popup は、開いているウィンドウに存在するすべてのタブグループを一覧表示し、グループごとにサスペンドを実行する操作を提供しなければならない（SHALL）。一覧には、TabHerd のルールで作られたグループと、利用者が手動で作成したグループの両方を含めなければならない（SHALL）。

#### Scenario: 手動作成したグループも一覧に表示される

- **WHEN** 利用者がブラウザの機能でタブグループを手動作成し、popup を開く
- **THEN** そのグループが一覧に表示され、サスペンド操作ができる

#### Scenario: 複数ウィンドウに存在する同名グループ

- **WHEN** 同じ名前のタブグループが複数のウィンドウに存在する状態で popup を開く
- **THEN** 一覧には popup を開いたウィンドウに属するグループだけが表示される

### Requirement: サスペンド対象の絞り込み

グループのサスペンドを実行すると、そのグループに属するタブのうち、アクティブタブとピン留めタブを除いたタブだけをサスペンドしなければならない（SHALL）。サスペンドの対象は、操作を行ったウィンドウ内の、そのグループのタブに限らなければならない（MUST）。

#### Scenario: アクティブタブは対象から除外される

- **WHEN** あるグループ内のタブのうち1つがアクティブな状態で、そのグループのサスペンドを実行する
- **THEN** アクティブなタブはサスペンドされず、それ以外の対象タブはサスペンドされる

#### Scenario: ピン留めタブは対象から除外される

- **WHEN** あるグループ内にピン留めされたタブが含まれる状態で、そのグループのサスペンドを実行する
- **THEN** ピン留めされたタブはサスペンドされず、それ以外の対象タブはサスペンドされる

#### Scenario: 他ウィンドウの同名グループには影響しない

- **WHEN** 同じ名前のタブグループが複数のウィンドウに存在し、一方のウィンドウでそのグループのサスペンドを実行する
- **THEN** 操作したウィンドウのグループのタブだけがサスペンドされ、他のウィンドウの同名グループのタブはサスペンドされない

### Requirement: 実行前の確認

「サスペンド前に確認する」設定が有効なとき、グループのサスペンドを実行する前に、利用者に実行の可否を確認しなければならない（SHALL）。確認で利用者が中止を選んだ場合、タブはサスペンドされてはならない（MUST NOT）。

#### Scenario: 設定が有効なときは確認が表示される

- **WHEN** 「サスペンド前に確認する」設定が有効な状態で、グループのサスペンドを実行する
- **THEN** 実行前に確認が表示される

#### Scenario: 確認で中止するとサスペンドされない

- **WHEN** 確認が表示された状態で、利用者が中止を選ぶ
- **THEN** そのグループのタブはサスペンドされない

### Requirement: 確認表示のON/OFF設定

options 画面は、「サスペンド前に確認する」設定を切り替える操作を提供しなければならない（SHALL）。この設定は保存されていないとき、有効（ON）として扱わなければならない（MUST）。

#### Scenario: 初期状態では確認が有効

- **WHEN** 設定を一度も変更していない状態で、グループのサスペンドを実行する
- **THEN** 実行前の確認が表示される

#### Scenario: 設定を無効にすると確認が表示されない

- **WHEN** options 画面で「サスペンド前に確認する」設定を無効にしてから、グループのサスペンドを実行する
- **THEN** 実行前の確認は表示されず、対象タブが直接サスペンドされる
