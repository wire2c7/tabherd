# Proposal

## Why

TabHerd はタブグループを自動で管理する拡張機能だが、まだ機能がない。最初の機能として、URL の条件でタブを自動的にタブグループへまとめる機能を作る（親 Issue #13）。

## What Changes

- グループのルール（グループ名・色・条件の一覧）を定義し、拡張機能のローカルストレージに保存する（#14）
- 条件は URL の部分一致と正規表現の2種類。1つのルールに複数の条件を指定でき、どれか1つに一致すれば一致とみなす（#14）
- タブの URL が変わったとき（新しく開いたタブを含む）に判定し、一致したルールのタブグループへ入れる。一致しなくなったタブはグループから外す（#15）
- インストール・更新時、ブラウザの起動時、ルールの変更時に、開いているすべてのタブを判定し直す（#15）
- ルールの順番を、複数のルールに一致したときの優先度と、タブバー上のグループの並びに使う（#14・#16）
- ツールバーのポップアップを追加し、オプションページと同じルールの設定画面を出す。ルールの追加・編集・削除（#17）とドラッグでの並び替え（#18）ができる

## Capabilities

### New Capabilities

- `grouping-rules`: グループのルールの内容・保存・URL がどのルールに一致するかの判定
- `auto-grouping`: ルールに従ったタブのグループ化・解除と、タブバー上のグループの並び
- `rule-settings-ui`: ポップアップとオプションページで、ルールを追加・編集・削除・並び替えする画面

### Modified Capabilities

なし

## Impact

- `entrypoints/background.ts`: 仮の処理を、タブ・ストレージのイベントを受けてグループを管理する処理に置き換える
- `entrypoints/options/`: 見出しだけの画面を、設定画面のコンポーネントに置き換える
- `entrypoints/popup/`: 新規追加（manifest に `action.default_popup` が加わる）
- ルールの型・判定・保存・グループ操作の計画を置くモジュールを新規に追加する
- 権限は既存の `storage`・`tabGroups`・`tabs` で足り、追加しない
- 並び替えは依存を増やさず HTML5 Drag and Drop で作る（design.md）。判断は #18 で ADR に残す
