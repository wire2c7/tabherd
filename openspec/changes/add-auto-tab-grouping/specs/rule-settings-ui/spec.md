# Spec Delta

## Purpose

ツールバーのポップアップとオプションページで、グループのルールを追加・編集・削除・並び替えする設定画面の振る舞いを定める。

## ADDED Requirements

### Requirement: 設定画面の表示場所

設定画面は、ツールバーのアイコンから開くポップアップと、拡張機能のオプションページの両方に、同じ内容・同じ操作で表示しなければならない（MUST）。

#### Scenario: ポップアップから開く

- **WHEN** ツールバーの TabHerd のアイコンをクリックする
- **THEN** ポップアップにルールの一覧が表示される

#### Scenario: オプションページから開く

- **WHEN** 拡張機能のオプションページを開く
- **THEN** ポップアップと同じルールの一覧が表示される

### Requirement: ルールの一覧

設定画面は、保存されたルールを一覧の順に表示し、各ルールのグループ名・色・条件を確認・編集できなければならない（MUST）。ルールが1つもないときは、ルールを追加するよう促す表示をしなければならない（MUST）。

#### Scenario: ルールがない

- **WHEN** ルールが1つも保存されていない状態で設定画面を開く
- **THEN** ルールがないことと、追加する操作が表示される

### Requirement: ルールの追加・編集・削除

設定画面では、ルールを一覧の末尾に追加し、グループ名・色を編集し、ルールを削除できなければならない（MUST）。条件は1つのルールに複数追加・削除でき、それぞれ種類（部分一致・正規表現）と値を編集できなければならない（MUST）。変更は保存の操作なしに即座に保存しなければならない（MUST）。

#### Scenario: ルールを追加する

- **WHEN** ルールを追加する操作をする
- **THEN** 一覧の末尾に新しいルールが加わり、保存される

#### Scenario: 条件を追加する

- **WHEN** ルールに条件を追加し、種類に正規表現を選んで値を入力する
- **THEN** ルールの条件が1つ増え、保存される

#### Scenario: 閉じて開き直す

- **WHEN** ポップアップでルールを編集し、ポップアップを閉じてから開き直す
- **THEN** 編集した内容が表示される

#### Scenario: ルールを削除する

- **WHEN** ルールを削除する操作をする
- **THEN** 一覧からルールが消え、保存される

### Requirement: 入力の検証

構文が不正な正規表現の条件、空のグループ名、一覧で上にあるルールと同じグループ名には、該当する入力欄の近くにエラーを表示しなければならない（MUST）。値が空の正規表現の条件は入力途中でもあるため、エラーを表示してはならない（MUST NOT）。エラーがあっても入力内容は保存し、そのルール・条件は自動グルーピングで無効として扱われなければならない（MUST）。

#### Scenario: 不正な正規表現

- **WHEN** 正規表現の条件に `(` を入力する
- **THEN** その条件の近くに正規表現が不正である旨のエラーが表示される

#### Scenario: グループ名の重複

- **WHEN** 2番目のルールのグループ名を1番目と同じにする
- **THEN** 2番目のルールのグループ名の近くにエラーが表示される

### Requirement: ルールの並び替え

設定画面では、ルールをドラッグして一覧の順番を変えられなければならない（MUST）。マウスを使わずキーボードだけでも、ルールを1つ上・1つ下に移動できなければならない（MUST）。並び替えた順番は即座に保存しなければならない（MUST）。

#### Scenario: ドラッグで並び替える

- **WHEN** 2番目のルールを1番目の上までドラッグする
- **THEN** 2番目だったルールが1番目になり、保存される

#### Scenario: キーボードで並び替える

- **WHEN** 2番目のルールの「上へ移動」の操作をキーボードで実行する
- **THEN** 2番目だったルールが1番目になり、保存される
