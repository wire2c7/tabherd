# Spec Delta

## ADDED Requirements

### Requirement: ルールの読み込みの失敗

保存されたルールの一覧の読み込みが失敗したとき、設定画面は読み込み中の表示のままにしてはならない（MUST NOT）。失敗したことが利用者に分かる表示をし、もう一度読み込みを試す操作を示さなければならない（MUST）。読み込みに失敗しているあいだは、ルールの一覧の実体が無いため、ルールを追加する操作を無効にしなければならない（MUST）。もう一度読み込みを試す操作で読み込みに成功したときは、失敗の表示を消し、通常のルールの一覧の表示に戻らなければならない（MUST）。

#### Scenario: 読み込みが失敗する

- **WHEN** 保存されたルールの一覧の読み込みが失敗した状態で設定画面を開く
- **THEN** 読み込み中の表示の代わりに、読み込みに失敗した旨の表示ともう一度読み込みを試す操作が表示され、「ルールを追加」の操作は無効になる

#### Scenario: 再読み込みに成功する

- **WHEN** 読み込みに失敗した表示が出ている状態で、もう一度読み込みを試す操作をし、今度は読み込みに成功する
- **THEN** 失敗の表示が消え、読み込んだルールの一覧が表示され、「ルールを追加」の操作ができるようになる

#### Scenario: 再読み込みに失敗する

- **WHEN** 読み込みに失敗した表示が出ている状態で、もう一度読み込みを試す操作をし、再び読み込みに失敗する
- **THEN** 読み込みに失敗した旨の表示ともう一度読み込みを試す操作が表示されたままになる
