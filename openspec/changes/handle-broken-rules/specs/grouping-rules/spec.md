# Spec Delta

## ADDED Requirements

### Requirement: 保存されたルールの読み込み

保存されたルールの一覧の形が壊れていても、例外を出さずに読める部分を使わなければならない（MUST）。保存値が一覧でなければ、空の一覧として扱わなければならない（MUST）。ID かグループ名が読めないルールと、ID が上のルールと同じルールは除かなければならない（MUST）。条件の一覧が読めないルールは条件を持たないものとし、種類か値が読めない条件はその条件だけを除かなければならない（MUST）。色が読めないルールの色は grey としなければならない（MUST）。読み込みで保存されたルールを書き換えてはならない（MUST NOT）。バックグラウンドの処理は、壊れた値を読んだときに警告のログを残さなければならず（MUST）、壊れていない値を読むまでは、バックグラウンドの処理が止まって起き直しても、ブラウザを起動し直すまで同じ警告を繰り返してはならない（MUST NOT）。

#### Scenario: 条件の一覧が壊れている

- **WHEN** ルール「開発」の条件の一覧が `null` で、ルール「資料」（部分一致 `.org`）が正しく保存されている状態で、`https://example.org/` のタブを判定する
- **THEN** 判定は例外を出さずに続き、タブは「資料」に一致する

#### Scenario: 保存値が一覧でない

- **WHEN** 保存されたルールの値が文字列である
- **THEN** ルールの一覧は空として扱われる

#### Scenario: 壊れた値を読み続ける

- **WHEN** 保存されたルールが壊れた状態のまま、バックグラウンドの処理がルールを何度も読む
- **THEN** 警告のログは最初の1回だけ残る

#### Scenario: バックグラウンドの処理が起き直す

- **WHEN** 保存されたルールが壊れた状態で警告のログが残った後、操作が無くバックグラウンドの処理が止まり、タブを開いて起き直す
- **THEN** 警告のログは増えない
