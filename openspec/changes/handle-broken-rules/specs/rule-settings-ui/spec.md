# Spec Delta

## ADDED Requirements

### Requirement: 壊れたルールの表示

保存されたルールの形が壊れているとき、設定画面は例外を出さずに、「保存されたルールの読み込み」（`grouping-rules`）のとおりに読めた一覧を表示し、ルールの一部が壊れていた旨の警告を表示しなければならない（MUST）。開いただけで保存されたルールを書き換えてはならない（MUST NOT）。利用者がルールを変更したときは、読めた一覧に変更を加えて保存し、警告を消さなければならない（MUST）。

#### Scenario: 壊れたルールがある

- **WHEN** ルール「開発」の条件の一覧が `null` の状態で設定画面を開く
- **THEN** ルール「開発」が条件なしで表示され、ルールの一部が壊れていた旨の警告が表示される

#### Scenario: 編集して保存し直す

- **WHEN** 壊れたルールの警告が出ている状態で、いずれかのルールを編集する
- **THEN** 読めた一覧に編集を加えたものが保存され、警告が消える
