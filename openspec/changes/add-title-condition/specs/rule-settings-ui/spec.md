# Spec Delta

## MODIFIED Requirements

### Requirement: ルールの追加・編集・削除

設定画面では、ルールを一覧の末尾に追加し、グループ名・色を編集し、ルールを削除できなければならない（MUST）。条件は1つのルールに複数追加・削除でき、それぞれ対象（URL・タイトル）・種類（部分一致・正規表現）と値を編集できなければならない（MUST）。変更は保存の操作なしに即座に保存しなければならない（MUST）。

#### Scenario: ルールを追加する

- **WHEN** ルールを追加する操作をする
- **THEN** 一覧の末尾に新しいルールが加わり、保存される

#### Scenario: 条件を追加する

- **WHEN** ルールに条件を追加し、種類に正規表現を選んで値を入力する
- **THEN** ルールの条件が1つ増え、保存される

#### Scenario: 条件の対象をタイトルに変える

- **WHEN** 条件の対象を URL からタイトルに変える
- **THEN** その条件はタイトルを対象にした条件として保存される

#### Scenario: 閉じて開き直す

- **WHEN** ポップアップでルールを編集し、ポップアップを閉じてから開き直す
- **THEN** 編集した内容が表示される

#### Scenario: ルールを削除する

- **WHEN** ルールを削除する操作をする
- **THEN** 一覧からルールが消え、保存される
