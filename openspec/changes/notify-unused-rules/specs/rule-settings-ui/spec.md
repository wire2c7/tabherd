# Spec Delta

## ADDED Requirements

### Requirement: 使われないルールの通知

使われないルール（grouping-rules の「ルールの有効性」で重複して無効になるルールと、グループ名が空でグループのタイトルを持っている（auto-grouping の「ルールの変更の反映」）ルール）があるときは、設定画面の一覧の上にその件数を表示しなければならない（MUST）。追加したばかりで名前を入れていないルール（グループ名が空で、グループのタイトルを持っていないルール）は数えてはならない（MUST NOT）。使われないルールがあるあいだは、設定画面を閉じていても、拡張機能のアイコンにバッジ「!」を付け、アイコンの説明に件数を出さなければならない（MUST）。使われないルールが無くなったら、表示とバッジを消し、説明を元に戻さなければならない（MUST）。

#### Scenario: 使われないルールがある

- **WHEN** ルール「開発」「資料」があり、「資料」のグループ名を空にする
- **THEN** 設定画面の一覧の上に「使われないルールが 1 件あります」と表示され、拡張機能のアイコンにバッジ「!」が付き、説明に件数が出る

#### Scenario: ルールを追加した直後

- **WHEN** 「ルールを追加」でルールを追加し、まだ名前を入れていない
- **THEN** 一覧の上の表示もバッジも出ない（入力欄の下には、グループ名を入力するよう促すエラーが出る）

#### Scenario: 使われないルールが無くなる

- **WHEN** グループ名が空のルールに名前を入れる
- **THEN** 一覧の上の表示とバッジが消え、アイコンの説明が元に戻る
