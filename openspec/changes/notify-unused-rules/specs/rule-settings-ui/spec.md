# Spec Delta

## ADDED Requirements

### Requirement: 使われないルールの通知

使われないルール（グループ名が空のルールと、grouping-rules の「ルールの有効性」で重複して無効になるルール）があるときは、設定画面の一覧の上にその件数を表示しなければならない（MUST）。使われないルールがあるあいだは、設定画面を閉じていても、拡張機能のアイコンにバッジ「!」を付け、アイコンの説明に件数を出さなければならない（MUST）。使われないルールが無くなったら、表示とバッジを消し、説明を元に戻さなければならない（MUST）。

#### Scenario: 使われないルールがある

- **WHEN** ルール「開発」「資料」があり、「資料」のグループ名を空にする
- **THEN** 設定画面の一覧の上に「使われないルールが 1 件あります」と表示され、拡張機能のアイコンにバッジ「!」が付き、説明に件数が出る

#### Scenario: 使われないルールが無くなる

- **WHEN** グループ名が空のルールに名前を入れる
- **THEN** 一覧の上の表示とバッジが消え、アイコンの説明が元に戻る
