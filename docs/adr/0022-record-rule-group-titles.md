# 0022. ルールが持っているグループのタイトルを記録する

- ステータス：Accepted
- 日付：2026-10-05
- 関連 Issue：#70

## コンテキスト

設定画面はグループ名を1文字入力するたびに保存し、background は 300ms 待ってから反映する。打ち直しの途中で名前が空になったり、ほかのルールと同じ名前を一時的に通ったりすると、ルールが無効になり、そのグループのタブが外れる。続けて名前を入れると、グループが作り直される。

前提と制約:

- Chrome のタブグループが持てるのはタイトルと色だけで、拡張機能の値（ルールの ID 等）を付けられない。グループとルールはタイトルで結び付けるしかない
- ルールが無効なあいだもグループを残すには、どのタイトルのグループがそのルールのものかを、ルールの名前とは別に覚えておく必要がある。ブラウザを起動し直した後も続けたい
- 名前が重なったときに一覧で上のルールを有効にすると、上のルールが下のルールの名前を一時的に通ったとき、上のルールのグループのタイトルが下のルールと同じになり、以後は区別できなくなる

## 検討した選択肢

### 記録する場所

- **background が `local:ruleGroupTitles` に、ルールの ID からタイトルへの対応を保存する**：書くのが background だけで、競合しない。ブラウザを起動し直しても残る
- **ルールの保存値（`local:rules`）に持たせる**：1か所にまとまるが、設定画面と background の両方が同じ値を書き、競合する
- **`session:` に保存する**：ブラウザを閉じると消え、起動し直した後に無効なルールのグループを扱えない

### 名前が重なったときに有効にするルール

- **すでにそのタイトルを持っているルール（無効なあいだ持ち続けるものを含む）**：既存のグループのタイトルが別のルールのものにならない。後から同じ名前にしたルールが無効になる
- **一覧で上のルール（これまでどおり）**：分かりやすいが、上のルールが下のルールの名前を通る打ち直しで、同じタイトルのグループが2つになる

## 決定

background が、ルールの ID からそのルールが持っているグループのタイトルへの対応を、反映のたびに `local:ruleGroupTitles` に保存する。有効なルールは名前を、無効なルールは無効になる前のタイトルを持ち続け、そのグループはルールの位置に置いたまま触れない。

名前が重なったときは、すでにそのタイトルを持っているルールを有効にし、どのルールも持っていなければ一覧で上のルールを有効にする。設定画面も記録を読んで同じ判定をする。

## 結果

- 打ち直しの途中で一時的に無効になっても、グループは作り直されず、名前を入れるとタイトルが変わる
- 名前を空にしたまま残したルールのグループは、ルールを削除するまで残る
- 重複の判定が background の記録に依存し、記録が書かれる前（反映の 300ms の待ちのあいだ）は上のルールが優先される
- 保存する値が1つ増える。WXT を置き換えるときは、この値も読めるようにする必要がある（ADR 0021）
