# 0011. ルールの並び替えにライブラリを使わず HTML5 Drag and Drop を使う

- ステータス：Accepted
- 日付：2026-09-29
- 関連 Issue：#18

## コンテキスト

設定画面（ポップアップとオプションページ）で、ルールの一覧をドラッグで並び替えられるようにする。ルールの順番は、複数のルールに一致したときの優先度と、タブバー上のグループの並びを表す。マウスを使わずに並び替える手段も要る。

並び替えるのは縦1列の一覧だけで、一覧の間の移動や入れ子はない。UI は Preact で作っている（ADR 0003）。依存パッケージは ADR 0006 の設定（公開からの待ち時間・`trustPolicy`）で審査しており、増えるほど更新と審査の手間が増える。

## 検討した選択肢

- **dnd-kit**：キーボード操作・読み上げ・自動スクロールまで揃う。React 向けのため、Preact では `preact/compat` へのエイリアスの設定が要り、依存も増える
- **SortableJS**：フレームワークに依存せず、アニメーションも付く。DOM の要素を直接並べ替えるため、Preact の仮想 DOM が持つ並びと食い違い、描画し直すと元に戻る・二重になるといった不整合を避ける工夫が要る
- **HTML5 Drag and Drop（ライブラリなし）**：`draggable` と `dragstart`・`dragover`・`drop` だけで作れ、依存が増えない。並びは Preact の state として持つため仮想 DOM と食い違わない。タッチ操作とキーボード操作には対応しないため、別の手段が要る

## 決定

ライブラリを使わず、HTML5 Drag and Drop で並び替える。キーボード（とタッチ）の操作には、各ルールに「上へ」「下へ」のボタンを置いて対応する。

縦1列の並び替えだけなら、HTML5 Drag and Drop で足りる。キーボードの操作をボタンで別に用意すれば、dnd-kit の利点の多くは要らなくなり、依存と `preact/compat` の設定を増やさずに済む。

## 結果

- 依存パッケージが増えない。並び替えの位置の計算は純粋関数にしたため、Vitest で確かめられる
- ドラッグ中のアニメーションはない。差し込み先は線で示す
- ドラッグは各ルールの左端のハンドルから始める。ルール全体を `draggable` にすると、入力欄の文字をマウスで選択できなくなるため
- タッチ操作ではドラッグできず、「上へ」「下へ」のボタンを使う。拡張機能の設定画面はデスクトップの Chrome で使うため、影響は小さい
- 一覧の間の移動・入れ子など、並び替えが複雑になったら、ライブラリの導入を再検討する
