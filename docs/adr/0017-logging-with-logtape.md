# 0017. LogTape でログを出し、エラーの前後のログを端末にだけ保存する

- ステータス：Accepted
- 日付：2026-10-02
- 関連 Issue：#52

## コンテキスト

ログは `console.error` の2か所だけだった。開発中は処理の流れ（どのイベントで何件のタブを判定し、どの操作を出したか）を追えない。リリース後は、利用者の手元の Service Worker の console に出たエラーが消え、報告を受けても当時の状況が分からない。

前提と制約:

- 処理の中心は background の Service Worker で、`window`・`document`・`localStorage` は使えない。30秒操作が無いと止まり、次のイベントで起き直す
- `host_permissions` は無く、外部へ送るには権限の追加と、Chrome Web Store でのプライバシーの申告が要る
- 書き出したログは、公開の GitHub Issue に添付される
- 依存は pnpm の `minimumReleaseAge`・`trustPolicy` で審査している（ADR 0006）

## 検討した選択肢

ログの届け方:

- **端末に保存し、利用者が書き出して報告に添付する**：外部への送信も、そのための権限も要らない。利用者が報告しない限り届かない
- **Sentry 等へ自動で送る**：報告を待たずに届く。権限の追加、プライバシーの申告、サービスの費用と運用が要る。拡張機能では `Sentry.init()` を使えず、エラーは手で捕まえて送ることになる

ライブラリ（サイズは最小の構成で esbuild で minify・gzip した値）:

- **LogTape**：依存なし、36 KB（gzip 11 KB）。カテゴリの階層ごとのレベル、構造化したログ、差し替えられる sink を持つ。sink は `(record) => void` を書くだけで作れ、外部へ送ることにした場合も Sentry の sink を足せる
- **pino**：ブラウザ版は 9 KB（gzip 3.7 KB）。強み（JSON の高速な出力、transport、worker thread）は Node.js 向けで、ブラウザ版は console のラッパーと `transmit` だけになる
- **loglevel**：4 KB（gzip 1.7 KB）。レベル付きの console のラッパーだけで、構造化したログや出力先の差し替えが無い。最後のリリースは 2024-09
- **自作**：1〜2 KB。カテゴリごとのレベル、構造化したログ、出力先の差し替えを自分で書いて保守することになる

サイズについて:

- LogTape で `background.js` は minify 後 15 KB から約 51 KB になる
- 増えた分の読み込み・実行の時間は、Node（同じ V8）で数 ms だった。Service Worker が起き直すたびにかかるが、タブがグループに入るまでの遅れとして体感できる量ではない

## 決定

- 外部へは送らない。warning 以上のログが出たときに、その直前のログと一緒に `chrome.storage.local` に保存し、オプションページから利用者が JSON ファイルとして書き出す。保存は直近 500 件まで
- ログは LogTape で出す。開発ビルドでは debug 以上を、リリース版では warning 以上を console に出す
- エラーの前のログは、LogTape の `fingersCrossed` ではなく、自前のバッファで溜める。`fingersCrossed` は一度発動すると Service Worker が止まるまで以降のログをすべて流すため、エラーの後に操作が続くと、debug のログが 500 件を埋めてエラー本体を押し出す
- ログには ID・件数・処理の種類・エラーだけを入れ、URL・タイトル・グループ名・ルールの内容は入れない。記録するもの・しないものはオプションページで利用者に示す
- 保存するのは background のログだけにする。ポップアップ・オプションページの UI のログは console のままにする

## 結果

- 利用者は、書き出したファイルを確認せずにそのまま公開の Issue に添付できる。代わりに、URL やルールが原因の不具合は、ログだけでは再現できず、利用者に聞く必要がある
- 利用者が報告しない不具合は届かない。外部へ送ることにする場合は、新しい ADR で判断する
- ログに入れる値は、ログを出す側で選ぶ。新しいログを足すときは、URL・グループ名が入らないようにする（テストで確かめる）
- 拡張機能のサイズは約 36 KB（minify 後）増える
